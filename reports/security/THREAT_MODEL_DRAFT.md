# P00 威胁模型初稿

## 范围与安全目标

P00 只覆盖本地工程、依赖供应链、规格/证据完整性和 Live 锁。它不接入行情、社交、
账号、私有 API 或真实交易基础设施。首要目标是：秘密零落盘、真实订单不可达、来源
默认拒绝、构建可复现、阶段证据不可伪装为已验收业务能力。

## 资产与信任边界

受保护资产包括冻结规格及哈希、lockfile、源码和 CI、阶段状态与测试证据、未来秘密
引用名称。信任边界位于：用户输入与仓库、包注册表与本地构建、外部内容与来源策略、
Web 展示与交易能力、研究进程与未来账户适配器之间。

## 威胁、控制与验证

| 威胁 | P00 控制 | 验证 |
|---|---|---|
| 依赖投毒或构建脚本滥用 | 精确锁定、严格 peer、单包 `allowBuilds`、SBOM/漏洞/许可证扫描 | frozen install、审计脚本、合规报告 |
| 密码、Cookie、验证码或密钥进入仓库/日志 | 不请求值、只允许逻辑引用、秘密扫描和边界测试 | detect-secrets、`tests/security/` |
| 环境变量或配置意外打开 Live | 代码常量、配置、空适配器注册表、启动断言四重锁 | 负向 Live 锁测试 |
| 导入模块时联网、读秘密或下单 | 模块无 I/O 初始化；导入时拦截网络、进程和秘密读取 | 导入副作用测试 |
| 未授权来源被当作可处理数据 | `SourceProcessingPolicy` schema、空 allowlist、默认 `DENY` | 来源策略契约测试 |
| 规格或报告被悄然替换 | 冻结副本 SHA-256、需求矩阵、工件清单、commit 绑定 | 完整性与阶段报告测试 |
| Web 文案暗示可交易或提供控制入口 | 静态只读空状态，仅显示 `DEVELOPMENT / LIVE LOCKED` | 单元、构建、Chromium E2E |
| 测试失败被 skip 或文字掩盖 | 严格 pytest、机器退出码、结构化 `TEST_RESULTS.json` | 本地/远程 CI |

## 剩余风险

- NautilusTrader 上游成熟度为 Beta，且在 Python 3.13/3.14 回放中产生 pandas 弃用
  警告；当前契约通过不代表执行或实盘就绪。
- 本机没有 Docker、GPU 或 CUDA，相关能力只能标记 unavailable，不能声称已验证。
- 远程 CI 尚未实际运行；本地完整流水线是 P00 的执行证据，远程工作流只是可复现入口。
- 依赖审计只能反映扫描时可见公告；后续阶段需要持续扫描和锁定来源治理。

任何新增网络采集、账号、数据库、消息总线、交易适配器或解锁机制均超出 P00，必须在
相应阶段重新建模并验收。
