# P00 来源与权限访问请求

P00 不需要任何账号、秘密或付费订阅。以下问题只决定未来阶段能否规划接入；未提供
时保持 `not_provided` 和默认拒绝，绝不猜测：

- 原始市场数据、历史实验、旧策略和 `R331` 资料是否存在；如存在，仅提供只读绝对路径；
- 可供数据使用的磁盘上限，以及 Windows、WSL、Docker、GPU 的使用偏好；
- 聚宽账号可用的数据范围、市场、频率、导出能力与额度文字说明；
- 是否愿意未来申请 X Developer 项目，以及批准 use case 和月度硬上限；
- Telegram 公开或已授权频道 allowlist，以及是否准备专用研究账号；
- YouTube Data API、GitHub API/Webhook 的未来只读权限意向；
- 新闻/RSS/宏观/链上订阅的供应商、套餐、地域、再分发和额度限制；
- 独立 Testnet 账号是否可用；不得提供登录信息或任何凭据；
- 风险偏好、最大研究预算、允许市场、禁止资产和损失承受问卷。

回复只能包含路径、权限/订阅状态、预算或额度、地域说明、风险偏好，或本地秘密存储
中的逻辑引用名称。不得提供密码、Cookie、验证码、API Secret、私钥、session 文件、
提现凭据或任何可用 Token。P00 不读取这些输入，不登录，也不连接任何数据源或交易账户。
