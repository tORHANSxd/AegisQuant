# 新闻与社交来源访问矩阵

| 来源类别 | P00 状态 | 允许的 P00 行为 | 凭据状态 | 默认政策 |
|---|---|---|---|---|
| 官方交易所公告 | 未接入 | 仅核验公开条款与版本 | 不需要 | DENIED |
| GDELT / 公共 RSS | 未接入 | 无采集 | 不需要 | DENIED |
| 新闻与宏观订阅 | 未评估 | 只记录套餐、地域、额度、再分发约束 | 未配置 | DENIED |
| X API | 未接入 | 只记录未来申请、批准 use case 与硬上限 | 未配置 | DENIED |
| Telegram | 未接入 | 只记录公开/获授权频道 allowlist 要求 | 未配置 | DENIED |
| YouTube Data API | 未接入 | 无采集 | 未配置 | DENIED |
| GitHub API/Webhook | 未接入 | 仅浏览公开官方工程文档 | 未配置 | DENIED |
| Reddit / Discord / 微博 / TikTok | 未批准 | 不请求凭据、不采集 | 不适用 | DENIED |
| 付费新闻源 | 未评估 | 不购买、不试用、不绕过付费墙 | 不适用 | DENIED |

`DENIED` 表示没有逐来源处理政策时，采集、存储、云推理、训练、展示、导出和再分发
全部拒绝。公开可访问不等于已批准处理，缺少权限信息也不等于默许。
