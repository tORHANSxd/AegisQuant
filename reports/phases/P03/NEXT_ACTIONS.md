1. 若进入 P04，先完整读取任务书 P04 章节与 P03 八件套，建立独立需求追踪矩阵和实施
   计划；不得把 P03 文件改个编号就糊上去。
2. P04 继续保持 `LIVE_TRADING=false`，禁止账户、订单、私有 API、密码、Cookie、验证码、
   API Key 或 API Secret；公开数据 Provider 也必须逐个通过来源政策和契约门禁。
3. `P03-A01` 不需要自动重跑。只有项目业主撤销豁免、需要 24 小时稳定性声明或准备生产
   采集 SLA 时，才在合规区域重新运行完整 86,400 秒双流验收，并由新 ADR 替代 ADR-0007。
4. 在任何 Binance 端点或依赖升级前，重新核对官方稳定文档、Changelog 和实际公共契约，
   特别复测 USDⓈ-M REST 区域可达性、`/public`/`/market` 路由和订单簿序列语义。
5. 用户提供的 HKUDS/AI-Trader 可在未来研究/策略阶段作为非权威概念参考，固定观察提交
   `d03ff6c056b32ced735adf7c19ed8175adb1c8df`；由于仓库根目录未观察到许可证，不复制其
   源码，也不让它覆盖任务书、来源政策、PIT、风控或回放契约。
6. 持续保留 `accepted_with_waiver` 语义和开放风险；任何报告都必须将 `P03-A01` 标为
   `WAIVED` 而非 `PASS`。
