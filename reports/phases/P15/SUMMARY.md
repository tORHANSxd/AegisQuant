# P15 实施总结

P15 已完成任务书第 17 章的完整只读工作台。Web 端现有 15 个业务路由，覆盖账户、实时台、绩效、
执行、策略、模型、市场、全球事件情报、风险、研究、外部情报研究、数据质量、事故、系统和安全设置；
页面共用工作台框架，但保留各领域自己的指标、解释、来源、表格和图表，不存在“稍后实现”占位页面。

服务端 Read Model 扩展到 24 类投影、52 条记录和 52 个来源事件，全部携带截至时间、质量状态、来源
工件及 SHA-256。Read API 共 33 条 GET 路由，没有 POST、PUT、PATCH 或 DELETE；长时序在服务端以
确定性 min/max bucket 下采样，100,000 点证据压缩到 200 点时仍保留首末点、全局极值和受保护事件，
并提供 ETag、私有重验证缓存、游标窗口与固定表格渲染窗口。

执行页中的 2 个可见订单均可单击下钻到 Signal→Event Evidence→Model→Risk→Order→Fill→Ledger
七段链。链路明确区分 `VERIFIED`、`NOT_APPLICABLE` 和 `NOT_AVAILABLE`；当前 P06 基线未使用信号、
事件或预测模型，因此对应阶段如实标记为 `NOT_APPLICABLE`，没有伪造因果关联。

全局账户、时间、时区、策略和场所筛选、Ctrl+K 命令面板、当前视图导出与本地布局偏好已落地。
设置只保存非敏感显示偏好；没有密码、Cookie、验证码、API Secret、账户接入、下单、撤单、风险限额
编辑、模型发布或 Live 解锁入口。可访问性证据覆盖键盘、焦点、文本替代、颜色冗余、减少动画和
WCAG 2.2 AA 对比度；Chromium、Firefox、WebKit 共固化 6 份视觉基线。

完整流水线 46/46 通过：Python 3.13 为 620 项通过，Python 3.14.7 隔离候选环境为 581 项通过，均有
11 条上游弃用告警；P15 变异 7/7 全部击杀。Web 单元测试 19 项通过，Playwright 19 项通过、2 项按
浏览器能力设计跳过；本地生产工作台 p75 为 181ms，低于 1500ms 预算。六个 Web 门均直接由仓库内
Node 24.20.0 与 pnpm 11.24.0 启动，最终 CI 证据不再含主机 Node 24.12.0 的 engine 漂移。

按业主决定，本阶段没有运行 12h/24h 墙钟验收，也不生成 `ACCEPTANCE.md`。以上仅证明 P15 实现与
自动化门禁完成，不等于正式验收；没有连接真实账户、Testnet 或交易场所网络，没有索取或写入明文
秘密，`LIVE_TRADING` 继续锁定，P16 尚未开始。
