# P18 风险登记

- **没有获批策略（高，开放）**：P08 的 `linear-fused` 只在确定性开发 fixture 上胜出，最终 Holdout 仍
  锁定；没有足够证据支持 alpha、资本配置或 Live 候选，硬门 `approved-strategy-scope` 为 `FAILED`。
- **专用账户控制未验证（高，开放）**：没有连接真实账户，也没有专用低余额子账户、禁提现、IP 白名单
  和最小权限证据；在用户自行配置并逐项核验前不得存入凭据引用，更不得请求秘密值。
- **真实 Testnet 未验收（高，开放）**：P12 只完成确定性 Testnet 契约，没有真实网络成交、持续期、
  对账与故障证据；逻辑循环不能冒充真实场所运行。
- **外部告警与人工值守未闭合（高，开放）**：本地 SEV0 契约通过，但外部通知送达和完整 Canary 窗口
  的人工值守没有用户确认；关键告警无法送达时必须保持 `HALTED`。
- **目标 Linux 未验证（高，开放）**：镜像、IaC 和 Windows 本地契约通过，但没有目标 Linux 容器运行
  证据；不得把静态 compose 校验表述为目标环境发布成功。
- **异机备份未验证（高，开放）**：加密备份、篡改拒绝与本机恢复通过，但没有不同物理设备或异地存储
  的恢复证据；单机故障仍可能同时损失运行数据与备份。
- **墙钟验收与正式验收延期（高，开放）**：用户明确不执行 12h/24h，P18 的 7 项 acceptance 保持
  `in_progress`；55/55 自动门禁通过只说明实现质量，不改变 `NO_GO`。
- **Manifest 无发布信任锚（高，开放）**：当前签名使用可复现、未持久化的测试证据密钥，任何能替换
  文件的人也能替换公钥；它不提供发布者身份认证或 Live 授权，真实 Canary 必须另建受保护信任链。
- **未来资本配置风险（高，受控）**：L1/L2 的代码天花板虽然定义为 100/250 美元，但当前有效和操作
  上限全部为 0。未来任何非零值都必须同时满足更低用户政策、全部硬门、独立批准与单次人工解锁。
- **上游弃用告警（低，开放）**：Starlette TestClient 的 httpx2 迁移提示，以及 Nautilus/Pandas 的
  timedelta 弃用提示共 11 条；当前不影响结果，依赖升级时必须重新跑完整契约。
