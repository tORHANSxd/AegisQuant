# P16 后续动作

1. 完成 P16 证据提交和本地归档后，才可把阶段状态切换到 P17；P17 只做候选数据源、模型、基础设施
   和外部服务的受控评估，不购买服务、不上传项目数据，也不连接真实交易账户。
2. P17 对每个候选先记录官方契约、价格/授权、数据新鲜度、速率限制、隐私、安全、退出成本和可替代性，
   再做可复现 bake-off；缺少凭据、预算或网络条件时必须记为 `NOT_TESTED`，不得编造结果。
3. 继续把 HKUDS/AI-Trader 仅作为外部研究参考：先隔离审计许可证、依赖、数据泄漏和策略假设，再决定
   是否转译思想；禁止直接执行不可信脚本、复制未知许可证代码或把第三方收益声明当作本项目证据。
4. 在最终统一验收阶段再由业主提供并确认外部 SEV0/SEV1 渠道、目标 Linux/Docker 主机、真实 IdP/CA
   和异机备份介质；没有这些条件时 P18 的对应 Live readiness 必须保持 `NO_GO`。
5. 不创建 12h/24h 后台任务，不为 P16 生成 `ACCEPTANCE.md`。若未来恢复延期验收，应新建独立证据，
   不得改写本次实现证据。
6. 继续保持 `LIVE_TRADING=false`，不连接真实交易账户，不索取或写入明文密码、Cookie、验证码或
   API Secret，不执行真实或 Testnet 场所订单请求。
