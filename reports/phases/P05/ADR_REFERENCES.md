# P05 ADR 引用

| ADR | 对 P05 的约束 | 验证结果 |
|---|---|---|
| ADR-0001：运行时与版本政策 | Python 3.13 主运行时、3.14.7 候选契约和锁定依赖 | 两套运行时分别 238/201 passed；Node 版本警告登记为 P05-RISK-006 |
| ADR-0002：事件引擎选择 | Nautilus 只在实际语义满足时使用，会计权威事实保留领域契约 | Nautilus 兼容探测通过；P05 账本不把框架对象当权威存储 |
| ADR-0003：Live Trading 锁 | 阶段不得拥有真实账户、认证或订单发送能力 | 状态、安全扫描和固定夹具均证明锁定 |
| ADR-0004：P01 领域契约与 PostgreSQL 技术栈 | 复用强类型 ID、Money、Journal 不变量和 PostgreSQL/Alembic | 会计表、组合外键、精确数值与迁移契约通过 |
| ADR-0005：P02 列式数据底座与本地安全查询契约 | 输入事实必须保留时间、revision 与可重放边界 | P05 只消费确定性事件，重建哈希与状态一致 |
| ADR-0006：Binance 公开市场数据契约与安全边界 | 市场数据只能走公共无认证路径 | P05 未新增私有 API、账户或交易能力 |
| ADR-0007：P03 二十四小时连续流验收豁免 | 不执行、不拼接、不伪造 12/24 小时结果 | P05 CI 未调用 soak，风险与报告均不声明在线 SLA |
| ADR-0008：P04 多场所公共数据与事件来源契约 | 多场所与事件输入保持可追溯且不能直接变成交易动作 | P05 仅处理固定会计事件与模拟 venue snapshot |
| ADR-0009：P05 权威会计、FIFO、估值与签名策略 | 固化原生资产双重记账、FIFO、PnL、幂等、对账和 Ed25519 签名 | 18 项追踪、Golden、property、replay、reconciliation 与 mutation 证据完成 |

按业主建议审阅了 HKUDS/AI-Trader，但其浮点费用配置和 Agent-Native 平台边界不满足本项目
权威会计契约，因此没有复制实现、引入依赖或连接服务；差异与取舍已写入 ADR-0009。本轮未发现
其他必须偏离官方稳定契约或实际契约测试的情况。
