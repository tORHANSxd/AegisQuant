# P10 风险

## 已控制

- `P10-R01` 未来修订、删除状态或互动热度泄漏：所有内容版本和互动快照按 `available_at <= as_of`
  选择，首版与完整版本链均保留，并有延迟和未来互动负向测试。
- `P10-R02` 转发热度伪装成独立证据：近重复、引用、转发和共同上游归入 source family；热度与
  独立性分开计算，一百条同源转发最多记一个独立见证。
- `P10-R03` 未知权利或凭据泄漏：权利矩阵对云推理、训练、展示和导出失败关闭；凭据只允许本地
  秘密引用，缺失时进入 `AWAITING_CREDENTIALS`，秘密扫描命中 0。
- `P10-R04` 单条社交消息或 LLM 直接下单：Fast/Deep 均要求证据、Skeptic 与弃权；输出类型仅为
  Proposal，不存在 `OrderCommand` 或真实账户连接能力。
- `P10-R05` Dune 写入或不可复现查询：SQL 写操作拒绝，查询 ID、版本、SQL 哈希、参数、execution
  ID、结果哈希与可用时间进入注册表和结果清单。
- `P10-R06` 事后挑选最好视角：四视角使用相同样本、预算、成本和 OOS 规则，正负结果全部保留。

## 尚存且阻断对应正式验收项

- `P10-R07` 需要认证的生产来源未配置本地秘密引用；当前只证明请求、响应、配额和降级契约，不能
  声称完成持续生产采集。
- `P10-R08` 合成事件、行情和短样本只验证工程正确性，不证明真实世界预测增益、Alpha 或未来盈利。
- `P10-R09` P10 不提供假装覆盖所有语言的通用翻译器；真实翻译必须携带供应方、模型版本、输入/
  输出哈希、置信度和人工复核状态。
- `P10-R10` 社交、宏观、链上和官方站点契约会变化；上线前必须重新核对官方稳定文档并运行契约
  测试，不能把兼容回退静默当成主契约。
- `P10-R11` 来源可信度与独立性是可审计启发式，不是事实真伪证明；高影响事件仍需反证、冲突与
  结构化弃权，不能用热度替代人工判断。
- `P10-R12` 正式验收被项目业主统一后置。工程验证完成不等于阶段接受，更不允许解除 Live 锁。
