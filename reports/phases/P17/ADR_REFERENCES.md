# P17 ADR 引用

- `ADR-0022`：13 个候选、7 份有界试用协议、零批准预算、`NO_PURCHASE`、Databento 条件门、X API
  约束、官方交易事实权威、免费基线降级和 AI-Trader 仅参考的直接决策。
- `ADR-0021`：P16 私网部署、Secret 隔离、恢复与发布边界，是 Provider 未来接入时不得突破的运行基线。
- `ADR-0016`：P11 独立风险、风险决策绑定和不可旁路原则，确保研究数据源不能直接创建订单或放大风险。
- `ADR-0015`：P10 官方来源、事件重放、available-time 和第三方聚合非权威原则。
- `ADR-0014`：外部知识与未知许可证代码只允许安全审查和思想转译，不得直接执行或导入。
- `ADR-0010`：正式验收统一后置，阶段实现与自动化门禁完成不等于验收通过。
- `ADR-0003`：`LIVE_TRADING` 默认拒绝、失败安全和不可旁路锁定。
- `ADR-0001`：Python、Node、pnpm、PostgreSQL 与依赖版本政策。
