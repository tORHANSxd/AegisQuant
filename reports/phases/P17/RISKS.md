# P17 风险登记

- **商业 Provider 未做真实试用（高，开放）**：13 个候选只有官方文档桌面评审，真实样本、OOS 消融、
  延迟、缺口、修订/删除和净交易增量均为 `NOT_TESTED`；`NO_PURCHASE` 不能反向解释为候选没有价值。
- **许可与再分发权未闭合（高，开放）**：多数商业计划需要联系销售或在账户内确认用途、历史权限、
  派生数据和删除同步条款；在书面审查通过前不得抓取、缓存、训练、导出或注册为运行时 Provider。
- **实际总成本未知（高，开放）**：公开价格不能覆盖许可附加费、CME 权利、数据量、存储、运维和
  交易影响成本。7 份计划中的 1080 美元只是未来逐项审批上限草案，当前批准金额仍为 0。
- **新闻价值尚未实测（中，开放）**：recall、误报、lead time、重复率与风险覆盖的 fixture 只验证
  计算契约，不能作为 Benzinga、Event Registry、CryptoPanic、RavenPack、Bigdata.com 或 LSEG 的表现。
- **X API 价格和用途约束易变（中，开放）**：精确价格在 Developer Console，限流与计费相互独立，
  删除同步和 AI/ML 用途受政策约束；未来试用前必须重查官方契约并设置独立硬成本门。
- **AI-Trader 许可证未核验（中，开放）**：README 徽章与缺失的根 `LICENSE` 不足以授权代码复用；
  当前只保留思想级引用，未来如需复用必须固定 commit 并取得完整许可证文本。
- **正式验收未执行（高，开放）**：按业主决定不运行 12h/24h 或阶段正式验收，5 项 acceptance 保持
  `in_progress`；53/53 自动门禁通过不得表述为正式接受或 Live readiness。
- **既有外部缺口延续到 P18（高，开放）**：真实 Testnet、外部告警渠道、目标 Linux/Docker、真实
  IdP/CA、异机备份和长时间稳定性仍无正式证据，P18 必须据此保持 `NO_GO`。
- **上游弃用告警（低，开放）**：Starlette TestClient 的 httpx2 迁移提示，以及 Nautilus/Pandas 的
  timedelta 弃用提示共 11 条；当前不影响结果，依赖升级前仍须通过实际契约测试。
