# P04 ADR 引用

| ADR | 对 P04 的约束 | 验证结果 |
|---|---|---|
| ADR-0001：运行时与版本政策 | Python 3.13 主运行时、3.14.7 候选契约及锁定依赖 | 两套运行时分别 219/183 passed；Node 版本警告登记为 P04-RISK-007 |
| ADR-0002：事件引擎选择 | 优先验证 Nautilus，语义不满足时保留领域协议后的原生路径 | 本地 1.231.0 发现结果及原生回退证据通过 |
| ADR-0003：Live Trading 锁 | 阶段不得拥有 Live、账户或订单能力 | 状态、注册表、安全测试全部锁定 |
| ADR-0005：P02 列式/PIT 数据底座 | revision、available time、PIT 查询和本地安全边界 | 删除传播与互动快照 PIT 回放通过 |
| ADR-0006：Binance 公共市场安全边界 | 公共端点 allowlist、无认证、无私有能力 | 扩展至多场所后仍通过全部回归 |
| ADR-0007：P03 24 小时验收豁免 | 不执行、不拼接、不伪造 24 小时结果 | P04 CI 未调用 soak，豁免原样保留 |
| ADR-0008：P04 多场所公共数据与事件来源契约 | Canonical Exposure、场所差异、官方来源、访问状态和安全回退 | P04 35/35 需求验证通过 |

P04 未发现必须偏离官方稳定契约的新情况；XML 安全边界和 Python 3.14 候选运行器修正已记录
在 ADR-0008 的既有“固定契约测试与无新增依赖”决定及 P04 风险登记中，无需虚构新 ADR。
