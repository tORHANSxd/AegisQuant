# Secret Leak Runbook

## Detection and severity

- 扫描、日志、工件或人工报告发现凭据/会话材料，默认 `SEV0`。
- 本项目仍不接收、复制或展示疑似秘密值；事故只记录类型、位置哈希和时间。

## Immediate actions

1. 隔离受影响服务和工件，阻断外发；不要把值贴入聊天、工单或日志。
2. 由秘密所有者在原服务吊销/轮换，并核查使用、权限、提现/IP 白名单和审计记录。
3. 清理缓存与发布工件，重新运行秘密扫描、依赖扫描和最小权限验证。

## Forbidden actions

- 禁止在事故记录中粘贴原值、通过 Git 重写掩盖而不轮换、验证秘密是否“还能用”。
- 禁止要求密码、Cookie、验证码或 API Secret。

## Evidence and recovery

- 只保存秘密类型、脱敏定位、指纹、吊销时间、影响范围和复扫结果。
- 轮换、访问审计、零命中复扫和独立审批完成前保持 `HALTED`。
