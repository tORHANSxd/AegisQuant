# ADR-0002：事件引擎选择

- 状态：Accepted
- 日期：2026-08-31
- 范围：P00

## 决定

采用 NautilusTrader 作为事件驱动回放与未来 Paper/Live 语义研究的候选核心，但不
把它包装成自研框架，也不在 P00 建立交易适配器。P00 的唯一集成是固定输入、固定
时钟与固定输出的双重回放契约。

向量研究与事件回放保持两个明确层次：前者未来服务研究速度，后者服务成交、订单、
风险和账本语义。任何向量结果都不能直接作为执行证据。

## 后果

NautilusTrader 保留在独立依赖组中。契约失败时 P00 阻断；后续选择其他引擎必须新建
ADR，并保留同等或更严格的确定性与状态机证据。NautilusTrader 仍为 Beta，P00 的
通过不构成 Testnet、Canary 或 Live 许可。
