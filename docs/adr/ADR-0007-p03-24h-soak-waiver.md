# ADR-0007：P03 二十四小时连续流验收豁免

- 状态：Accepted
- 日期：2026-09-01
- 决策人：项目业主
- 豁免编号：`P03-WAIVER-001`
- 关联要求：`P03-A01`

## 背景

任务书要求 Binance Spot 与 USDⓈ-M 公开流真实连续运行至少 24 小时，且无无法解释的
sequence gap，才能把 `P03-A01` 记为通过。项目实际发起了两次非测试模式运行：第一次
运行 `34,949.94099589996` 秒后被外部中断，没有生成合格的最终验收结果；第二次运行
`11.6085772998631` 秒后，USDⓈ-M 官方 REST 盘口快照端点返回 HTTP 451，运行失败。

这两次运行都不是 24 小时合格证据。项目业主于 2026-09-01 明确决定“不需要进行这个
24h 验收”，并确认继续下一环节。

## 决策

1. `P03-A01` 状态记为 `waived`，不得记为 `verified`、`passed` 或任何等价表述。
2. P03 关闭状态使用 `accepted_with_waiver`，明确区别于无条件 `accepted`。
3. 不创建 `reports/data/BINANCE_24H_SOAK.json`；关闭态契约测试必须验证该合格证据不存在。
4. 两次实际运行只形成失败尝试摘要 `reports/data/BINANCE_SOAK_ATTEMPT_SUMMARY.json`。
5. 除 `P03-A01` 外，P03 的 19 项任务与验收要求仍必须全部 `verified`，所有 CI、安全、
   双 Python、离线回放和 `LIVE_TRADING` 锁门禁仍须通过。
6. P04 只能在 P03 报告、工件清单、阶段状态和 Git 证据全部固化后另行启动。

## 后果

- 项目不得宣称 Binance 双市场公开流已通过 24 小时稳定性、换线或区域可达性验证。
- P03 公开市场数据适配器仍仅用于数据研究与确定性回放；本决策不授予账户、订单、私有
  API 或实盘权限。
- USDⓈ-M REST 在当前网络区域的 HTTP 451 被保留为开放风险；不得通过私有代理、账户
  凭据或未批准端点绕过。
- `LIVE_TRADING` 继续锁定，P04 及后续阶段也不能借本豁免解锁。

## 撤销或替代条件

若未来要声称 24 小时连续稳定性、准备生产采集 SLA，或项目业主撤销豁免，必须在允许
访问 Binance 公共端点的合规区域重新执行不少于 86,400 秒的完整双流运行，满足任务书
的 gap、恢复、换线、主机休眠和安全边界条件，并通过新 ADR supersede 本记录。
