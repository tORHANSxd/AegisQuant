# ADR-0003：Live Trading 永久默认锁

- 状态：Accepted
- 日期：2026-08-31
- 范围：全局，P00 首次落地

## 决定

Live 和订单提交使用代码常量、机器配置、空适配器注册表与启动断言四重锁定。P00
不实现解锁 API、命令、环境变量或界面控件。任何一层请求 Live 都以稳定错误码
`AQ-SECURITY-LIVE-LOCKED` 失败；错误不能降级为警告。

## 后果

研究、测试、CI 和 Web 均无真实下单能力，也不读取账户秘密。未来即使 P18 给出
`GO`，仍必须由任务书规定的独立、明确人工流程解锁；修改此 ADR 本身不构成授权。
