# ADR-0016：P11 组合构建、独立风险与单向安全状态政策

- 状态：Accepted by project owner through autonomous P11 execution authorization
- 日期：2026-09-02

## 背景

模型分数、事件判断和策略目标不是订单。若研究进程能直接把分数变成仓位、修改风险状态或调用
“紧急 override”，再漂亮的风控面板也只是贴在方向盘上的装饰。P11 需要把成本、容量、协方差、
分组约束、独立风险快照、预交易限制和熔断状态组成不可跳步的确定性链路，同时继续遵守 P08 的
Proposal-only 与 P10 的证据/传闻边界。

任务书要求示例风险数值不得误用于 Live，用户未确认时只能 Paper。当前项目也尚未进入 P12 的
Testnet、账户流和订单状态机，因此 P11 不应提前引入交易所账户、命令提交、自动恢复或私钥管理。

## 决定

1. 唯一允许的转换链为 `SignalInput → PortfolioProposal → RiskSnapshot + SignedRiskPolicy →
   RiskDecision → Paper OrderIntent`。缺少、过期、哈希不匹配或范围不一致的任一对象都失败关闭。
2. `PortfolioProposal` 没有订单能力。信号先截断到 `[-1, 1]`，再按置信度与不确定性折扣；低于
   no-trade zone 的信号保持当前权重。模型分数不能绕过成本或风险门禁。
3. 风险估计使用确定性对角 shrinkage，叠加显式因子协方差与市场状态乘数。资产覆盖缺失、矩阵
   非对称、方差为负、时间倒置或使用未来可用估计时拒绝构建组合。
4. 组合构建采用保守投影而不是“求解成功即通过”：风险预算、vol target、总 gross、资产、合约、
   策略、袖套、交易所、稳定币、相关簇、turnover、冲击和 ADV 容量约束只允许缩小候选。最终统一
   运行硬后置条件；约束之间不可同时满足时拒绝提案，不选择性忽略某项限制。
5. `RiskSnapshot` 独立生成并内容寻址，不能由策略提供“已经通过”的风险字段。数据或模型超过政策
   最大年龄时状态至少进入 `CAUTION`，并拒绝新增风险。
6. 风险政策采用严格 schema、版本、有效期、SHA-256 内容哈希和 Ed25519 公钥验签。运行时只接收
   可信公钥注册表；仓库、报告和接口不保存生产私钥。确定性测试签名明确标记为非生产夹具。
7. RiskDecision 对每腿保存原提案、当前权重、批准目标和批准变化。批准目标的绝对值不得超过原
   提案；预交易请求方向必须与批准变化一致，绝对变化不得更大，并再次检查订单、资产、策略和
   账户限制。
8. `NORMAL < CAUTION < REDUCE_ONLY < HALTED` 是自动状态的安全偏序。自动过程只能停留或向右移动；
   `RECOVERY` 只能由非 AI 人工从 `HALTED` 进入，并要求数据、模型、账本、保证金、流动性、交易所、
   安全和重大事件八项前置条件全部通过。自动恢复和风险 override API 不存在。
9. Kill Switch 对应 `HALTED`，不产生新 OrderIntent；`REDUCE_ONLY` 请求必须减少绝对敞口且不得穿零
   反向。状态、事件、原因码、告警和恢复序列全部可确定性重放。
10. 五类签名剧本覆盖官方安全事故、暂停提现、稳定币脱锚、重大监管和基础设施中断。确认事件必须
    有官方证据；传闻只能监控、收紧限额或在政策上限内减仓，减仓比例严格小于 100%，LLM 没有
    自由全平能力。
11. P11 的 `RiskPolicy` 与 `PortfolioConstructionPolicy` 均为 `EXAMPLE_ONLY`，允许阶段严格等于
    `PAPER`。不创建 Testnet/Live 账户、OrderCommand 或外部交易副作用。
12. 正式验收继续按 ADR-0010 延期；`LIVE_TRADING=false`、`live_trading_locked=true`，最终 Holdout
    仍锁定。

## 后果

- 策略无法拿“高置信度”当借口扩大 RiskDecision，研究包也不能导入风险实现；越权请求会得到稳定
  原因码，而不是被静默裁成一个看似成功的订单。
- 保守投影可能拒绝当前仓位、换手与容量互相冲突的组合。这比偷偷违反一个硬约束靠谱，毕竟风险
  引擎不是许愿池。
- `CAUTION` 对陈旧数据直接拒绝新增风险，可能降低交易频率，但避免用旧快照放行新风险。
- 公钥验签证明政策工件未被篡改，不解决生产密钥托管；生产签名和轮换必须在后续部署阶段另立 ADR。
- Paper 示例阈值只证明工程契约，不代表真实账户的风险承受能力、实盘校准或收益保证。

## 证据

- `tests/portfolio/`：信号、协方差、因子/状态风险、组合投影和七维分组约束。
- `tests/risk/`：政策验签、独立决策、八类熔断、预交易、状态回放、五类剧本和压力场景。
- `tests/property/test_portfolio_risk_properties.py`：随机约束、禁止放大和单向安全状态性质。
- `tests/architecture/test_risk_boundaries.py`：研究/模型包不依赖风险实现且公开 API 无 override/bypass。

## 回退条件

若未来采用外部优化器、硬件密钥、远程策略签名或 Testnet 账户，必须以官方稳定文档和实际契约测试
重新评估数值确定性、密钥轮换、失败语义和权限边界，并新建 ADR。任何回退都不能恢复自动风险放宽、
LLM 全平、未签名政策或绕过 RiskDecision 的订单路径。
