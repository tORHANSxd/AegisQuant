### 1.1 A3：不能把问题归结为费用太高

A3 相对 A1 少赚 10,619.45 USDT，同时少付执行成本 1,056.55 USDT。按报告成本机械加回，`(PnL_A3 + C_A3) - (PnL_A1 + C_A1) = -11,676.00 USDT`。

这表示费用节省不足以补偿被改变的收益路径；**不是已经测得模型本身损害 11,676 USDT**。路径变化同时包含候选接受/拒绝、入场延迟、持有机会、风险暴露和资本复利。

A3 平均暴露约为 A1 的 60.30%，但净利润约为 24.71%。这个比值不能当作风险匹配的反事实，也不能用收益除以平均暴露推算满仓收益。A3 最大回撤较低，所以不能声称 A1 在所有风险维度严格支配 A3；其当前 Sharpe 点估计更高，是优先保留 A1 为基线的理由之一。

### 1.2 A7：平均暴露约是 A1 的 1.32%

0.264% 相对 19.979% 不是轻微缩仓，而是两个非常不同的资金使用过程。应核对该值是完整时钟下 `sum(position_value)/sum(equity)` 的时间平均，而非币种平均、百分比二次除以 100 或只对有效预测采样。

低资金使用的机制可能是过滤减少参与时间、概率乘数、风险乘数等叠加，不能仅凭均值分配各项贡献。**不得把 0.264% 反向放大到 20% 或 100%，据此宣称可获得高收益。**

A7 的 Calmar 点估计并非一定差于 A1；本轮不使用某一个挑选出来的比率概括所有策略质量。

### 1.3 A1：交易调仓最值得先做可控优化，但不是确定 bug

2,022/104 ≈ 19.44 次成交/闭合持仓周期；A3 约 16.77 次。这可能包含合理风险调仓、部分成交、季度退出、价格漂移后修正等。

必须先区分订单、成交、部分成交和持仓周期。不能简单将 `2,022 - 2×104` 全部认定为无效交易，也不能把该频率称为高频交易。

A1 执行成本 2,912.38 USDT，相当于初始资金 5.82476%，相当于净利润约 20.65%。A3 成本/净利润约 53.26%。后一个比例以净利润为分母，**不是毛收益被扣去的百分比**。

将 A1 已报告成本仅在期末机械返还，期末约 67,016.52 USDT，按 365.25 天年化约 8.72%。这只是量级敏感性，不是零成本重跑结果，更不是允许动态再投资时的理论上界。它提醒我们：费用改进有价值，但还必须验证信号质量。

### 1.4 币种差异只用于归因，不用于删币

由 U1 各币四舍五入后的收益率计算，A3 相对 A1 的利润变化约为：BTC −3,088、ETH −580、BNB −8,365、SOL +3,213、XRP −1,800 USDT。

合计 −10,620，与精确组合差异相差 −0.55 USDT，属于报告百分比舍入层面的差异，不是发现账本错误。优先检查 BNB 的候选交易如何被过滤/推迟，但不能据此新增“只在 SOL 用 ML”的规则。

## 4. P1：给普通风险调仓加入缓冲区

### 4.1 单一预注册配置

本轮仅测试一个缓冲比例 `b=0.10`，作为工程研究起点，不是已证明的最优值。不得从测试收益挑选 5%、10%、20% 中的最好值。本轮不增加缓冲网格。

参考数量 `q_ref` = 同一币种、同一时点在满趋势信号下由当前 A1 风险模块输出的数量，不含任何 ML 概率乘数。当前 A1 为 long/flat；缓冲只在持仓期间约束常规风险调仓。

```text
q*    = 原 A1 风险层的原始目标数量
h     = 0.10 × q_ref
lower = max(0, q* - h)
upper = min(既有硬数量上限, q* + h)
```

当前实际数量在区间内时保持数量，不发新单。在区间外时交易到最近边界，不每次回到中心。

例：目标100单位、参考100单位，区间90–110。持有96不调；持有120减到110；持有70补到90。这个例子未考虑步长，只说明目标控制。

方法参考 Carver 的持仓缓冲及交易到边界的实现讨论 [S1]。10% 在此是独立研究假设，不把其期货研究绩效移植为本系统的结果。

### 4.2 安全和经济例外

趋势退出、明确硬风险减仓、停牌/下架应急处理不能被缓冲阻止。首次新趋势入场沿用 A1 目标，不用边界偷减入场仓位。零风险预算不是“继续占用最小仓位”的理由。

保持 A1 原风险检查时钟。不要把缓冲试验同时改成从4h到1d，或者从 UTC 日历检查改成首次成交后滚动24小时。

目标风险不等于硬风险上限：缓冲允许的偏离只能在原硬约束内。没有明确硬限额合同，先补合同，不能临时把风险放宽10%以改善收益。

数量取整后重新检查原资金、风险、step、min notional、max order 等约束。减少仓位不能因取整后仍超限而被标记完成；小于最小交易量的尾仓需要显式记录和风险升级，不能伪造清仓。

已有挂单时先由原订单管理器协调状态。目标一致可继续等待；目标冲突再撤单确认；在途成交必须进入账本。**参考组件的 RECONCILE_PENDING 不等于无条件撤单。**

### 4.3 配套参考组件

`buffered_target.py` 返回 HOLD、REQUEST_TARGET、RECONCILE_PENDING、BLOCKED 与目标数量；它不生成交易所订单、不做取整、不计算手续费、不保证满足组合联合约束。

1. 从最新本地 A1 获取原始数量与风险参考，不重新发明风险模型；
2. 传入 `regular_review_due_override`，沿用原 UTC 调仓日历；
3. `available_time` 使用所有依赖的最晚可用时间，并保留原 freshness 检查；
4. 将 REQUEST_TARGET 交回原执行器完成资金、数量和联合风险核验；
5. 联合硬风控不满足时采用原硬风险方案，不准被单币缓冲绕过；
6. 不用本函数的目标数量直接更新现金、仓位或净值；
7. 40 项独立单元测试不能替代本地集成、变形和回归测试。

经济验收：优先比较同一原风险预算下的净收益、Sharpe、回撤、尾部损失、回撤时长、换手和暴露。成本下降但错失大行情、或风险偷偷增大，不能判为改进。不得通过降低硬风险标准凑通过。

## 7. P4：只新增一个信号挑战者与一个经济基准

成本优化不会自动产生更强的信号。四组完成且工程可靠后，允许增加下面两个预注册配置，总新配置上限六个（现金核验及冻结证据复现不算新的策略搜索）。

### 7.1 F4：单一固定多周期趋势组合，研究假设而非已证实优势

预先固定 10/40、20/80、40/160 天三组 long/flat 趋势，确认与归一化规则一致，各占 1/3 信号预算：

```text
s(t) = [s_10_40(t) + s_20_80(t) + s_40_160(t)] / 3
q_target(t) = 原风险预算下满趋势数量(t) × s(t)
```

三组共享一个账户与一个风险预算，不是各自满额再相加。使用 F3 的边界与缓冲。不能按币种或季度挑选周期、给历史赢家加权；本轮不单独搜索三个周期的参数。

若当前 TrendPolicy 枚举不支持新周期，新增版本化政策，不修改旧冻结版本去重解释历史。

这是尝试降低单一10/40窗口依赖的假设，不保证三个高度相关信号提供足够分散。传统跨市场趋势研究 [S3] 不能证明五币现货必然盈利。

长窗口不能偷用不完整历史。评估起点前的预热和缺口后的有效性按各窗口因果定义；输出各子信号 readiness。禁止缩短 warmup 来追求收益。比较 F4 与 F3 时同时输出共同有效机会轴的诊断，避免把数据可用性差异冒充信号优势。若数据覆盖不足，登记阻塞，不临时改周期或删除不利时段。

F4 是一个新增信号实验，本轮不再加入突破、均值回归、新闻、推文或大模型等其他候选。

### 7.2 F5：同资本、同风险政策的持有型经济基准

五个相同子账户，以长期持有信号代替择时信号，其余使用 F3 的风险预算、缓冲、成本与硬约束。这不是原始100%满仓买持的替代品，而是检验择时是否比“用同样风险管理持有市场”提供额外价值。

另可报告不加风险层的原始 buy-and-hold，但不得用它与风险低得多的策略的累计收益直接证明优劣。

实现波动率不同的后验曲线缩放只可作为非可部署诊断；主要比较依赖事前可用、相同预算的风险规则，不得看完测试波动率再调整仓位。

## 8. A3/A7 的处置：保留证据，暂停将其作为主优化路线

### 8.1 先做机会归因，不先调概率阈值

以 A1 原始趋势机会定义 episode，记录 A3 是否接受、推迟、完全拒绝、因预测不可用而跳过。分别列已避开的亏损、错失的盈利、入场延迟、持有期差异以及资本/风险差异。

同时做固定参考名义金额的机会影子分析与权威资金账本的完整路径比较。前者用于拆机制，不可当作实际可交易收益。

A3 的冻结预测来自既定训练/校准窗口，不应当通过本轮历史结果重新校准后继续称为同一冻结预测。

### 8.2 将来重启 ML 的条件

只有在上述基础结构验证后且登记新的研究预算，才允许一个轻量模型与严格同校准零模型配对。两者需共享目标、训练窗口、校准样本、成本与可用性状态。

模型首先只参与入场，不重新加入概率缩仓和经济退出。验证对象是完整候选机会的净经济价值，而不是努力把胜率拉到55%以上。

当前标签与趋势持有期是否匹配仍需检查，但本轮没有新的本地代码可证明标签仍为旧20小时合同。先读取最新有效标签合同，再决定是否开展新目标研究；禁止未经证据沿用旧版本断言。

## 9. 成本、现金与 API 假设

本轮基础费用仍使用 U1 代理值，不降低10 bps来制造盈利。可以从本人环境取得真实费率证明后另开有清晰身份的情景，但不能把当前费率折扣倒灌进没有证据的历史。

Binance 官方提供账户级佣金查询与测试订单佣金计算说明 [S4]；所有涉及私有凭证的取数由用户本地工具执行，密钥不进入报告、压缩包或对话。

不把市价成交改成“触及限价就100% maker成交”。没有订单簿/排队证据时，不宣称限价单免费降低成本，也不能省略未成交与错失收益。

保留 step/min notional/market lot 等规则 [S5]。这些规则影响可执行数量；手续费优惠与免费交易是假设变更，不是编码优化。

现金年收益维持0。交易所/稳定币信用风险与策略收益分开，不能只比较现金收益率后把未验证策略当作确定增值。

## 10. 统计与最终验证

当前3.5年开发期已经反复使用。0次新拟合不意味着0次研究选择；策略设计、门槛、风险规则和报表选择都可能消耗同一批数据证据。

只使用共同时间索引做成对重采样，保留跨币和跨策略同时相关性。区块长度规则预先固定，考虑收益与平方收益的依赖；不能因为预测是6根就固定所有重采样为6根。可参考 arch 官方方法与例子 [S6]。

对于 F3−F0、F4−F3 等预注册主比较，报告差异估计与不确定性，而不只是各自单独的正收益区间。输出按年度、币种、市场阶段的描述性结果，不据此事后选币。额外分组分析明确标为探索性。

保留研究试验登记。DSR 等方法讨论了多重选择和非正态对历史指标的影响 [S7]，但不能机械用“6个新配置”代替项目迄今完整研究历史；历史不全时输出缺口，不编造有效试验数。

本轮没有确认此前未使用且满12个月的最终留出集；不读取已锁定留出数据，不把开发集改名为盲测。统计结果不够时可保留改善后的工程实现，但策略结论仍为 NO_PROVEN_ALPHA。

## 11. 执行、停止条件与自动归档

执行顺序：

1. 读取最新本地实现和已有 evidence，复现 A1；未确认的旧发现不得直接作为 bug 修复。
2. 增加原因日志并分类交易成本；识别到的真正缺陷独立桥接后冻结基线。
3. 集成缓冲区，加入原引擎回归/变形测试；增加跨季度完整状态继承。
4. 实际跑完 F0–F3 与预注册成本压力，输出所有成功和失败。
5. 工程与数据满足条件时，按已固定配置执行 F4/F5；不扩展搜索。
6. 输出明确结论及允许清单式证据包，而不是只交另一份未来计划。

停止只是作用于受阻步骤：缺少某组诊断字段则标未知，不伪造归因；A1复现不符则暂停收益优化排查；归档失败则停止该归档动作，遵守本地 skill 并保留源工作区。

报告已说归档因 codex-archive 分支退出。本轮不删除分支、不强推、不重写历史、不修改本地 skill、不偷偷换远程。使用用户本地现有研究文件不以成功生成远程提交为前提，但任何新运行都要保存源码/配置身份。
